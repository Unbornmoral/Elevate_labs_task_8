Interview Questions & Answers


What is Bootstrap? 
Bootstrap is a popular open-source front-end framework for building responsive and mobile-first websites using HTML, CSS, and JavaScript.

How to include Bootstrap in a project? 
You can include Bootstrap via CDN by adding the CSS and JS links in your HTML <head> and before the closing </body> tag respectively.

What is the grid system? 
Bootstrap’s grid system uses containers, rows, and columns to layout and align content. It’s based on a 12-column layout that adjusts across screen sizes.

What are utility classes? 
Utility classes are predefined classes in Bootstrap that help with spacing, alignment, colors, borders, and more — without writing custom CSS.

How do you customize Bootstrap? 
You can override Bootstrap styles by writing your own CSS, using Sass variables, or customizing components directly.

Difference between container and container-fluid? container has a fixed width and centers content, while container-fluid spans the full width of the viewport.

What are Bootstrap cards? 
Cards are flexible content containers with options for headers, footers, images, and buttons. They’re used to display blog posts, profiles, etc.

How to make responsive navigation? 
Use navbar-expand-lg with a toggler button and collapse component. Bootstrap handles responsiveness automatically.

What is a CDN? 
CDN stands for Content Delivery Network. It hosts files on distributed servers to load resources faster and reduce server load.

How to override Bootstrap styles?
Write your own CSS rules after the Bootstrap link in your HTML, or use more specific selectors to override default styles.
